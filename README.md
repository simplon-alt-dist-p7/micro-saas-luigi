# Micro SaaS Luigi

Micro SaaS Luigi est un espace de travail souverain destiné aux petites ESN et agences numériques françaises de 5 à 30 personnes. Sa vision est de centraliser progressivement le pilotage des missions clients afin de réduire la fragmentation et la dépendance à plusieurs solutions SaaS.

## Proposition de valeur

La V1 se concentre sur une fonctionnalité principale : suivre l’avancement d’une mission et faire valider ses livrables dans un portail client authentifié. L’équipe pilote ses tâches et livrables dans un Kanban interne tandis que le client consulte une vue simplifiée.

Le produit peut être déployé dans le cloud ou sur l’infrastructure de l’ESN afin de conserver la maîtrise des données. Les autres fonctions de centralisation seront évaluées après validation de cette première fonctionnalité.
